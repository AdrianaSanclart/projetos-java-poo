# Projetos Java POO

Coleção de pequenos sistemas em Java desenvolvidos para praticar fundamentos de programação orientada a objetos.

## Projetos incluídos

- `src/agencia-viagens`: classes para transporte, hospedagem, pacote de viagem e venda
- `src/rh`: hierarquia de funcionários com modelos assalariado e horista
- `src/impostos`: abstração, herança e interfaces para cálculo de impostos e pagamentos

## Conceitos demonstrados

- Classes e objetos
- Encapsulamento
- Herança
- Polimorfismo
- Classes abstratas
- Interfaces
- Entrada de dados e regras de negócio

## Como executar

Abra uma das pastas em uma IDE Java e execute a classe `Principal` correspondente. Os projetos são independentes e não exigem banco de dados.

## Escopo de publicação

Foram mantidos apenas os fontes. Arquivos compilados, configurações privadas do NetBeans e entregas acadêmicas não fazem parte deste repositório.
